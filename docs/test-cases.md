# Тест-кейси: «Домашня бібліотека» (SQLite-CRUD-Syniuk)

Середовище: Windows 10, Python 3, Flask 3.1, браузер Chrome. Тестова збірка: гілка `main`.

| ID | Назва | Передумови | Кроки | Очікуваний результат | Статус |
|---|---|---|---|---|---|

| TC-04 | Порожня назва | Форма «Нова книга» | Залишити «Назва» порожньою → «Зберегти» | Браузер не відправляє форму (поле required) | Pass |

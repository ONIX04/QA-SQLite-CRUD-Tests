# Баг-репорти

## BUG-001. Книга зберігається з назвою, що складається лише з пробілів
- **Severity:** Major  **Priority:** High
- **Кроки:** 1) Відкрити /add. 2) У полі «Назва» ввести три пробіли, «Автор» = «Тест». 3) «Зберегти».
- **Фактичний результат:** у таблиці з'являється книга з порожньою назвою.
- **Очікуваний результат:** повідомлення «Назва не може бути порожньою», запис не створюється.
- **Причина:** атрибут required пропускає пробіли, а сервер після `strip()` не перевіряє, що рядок не порожній.
- **Автотест:** `tests/test_validation.py::test_bug001_title_of_spaces_rejected`

## BUG-002. Немає перевірки діапазону року видання
- **Severity:** Minor  **Priority:** Medium
- **Кроки:** /add → «Рік видання» = 3025 → «Зберегти».
- **Фактичний результат:** книга збережена з роком 3025.
- **Очікуваний результат:** рік від 1 до поточного року включно.
- **Автотест:** `test_bug002_year_in_future_rejected`

## BUG-003. Кількість сторінок може дорівнювати 0
- **Severity:** Minor  **Priority:** Low
- **Кроки:** /add → «Кількість сторінок» = 0 → «Зберегти».
- **Фактичний результат:** збережено 0 сторінок.
- **Очікуваний результат:** значення має бути більшим за 0.
- **Автотест:** `test_bug003_zero_pages_rejected`

## BUG-004. Сервер приймає довільне значення статусу
- **Severity:** Major  **Priority:** Medium
- **Кроки:** /add → у DevTools змінити value опції списку «Статус» на «загублена» → «Зберегти».
- **Фактичний результат:** у базі зберігається статус «загублена».
- **Очікуваний результат:** сервер приймає лише «не прочитана», «читаю», «прочитана».
- **Причина:** перелік STATUSES використовується тільки для побудови списку у формі, але не для перевірки POST-даних.
- **Автотест:** `test_bug004_unknown_status_rejected`

## BUG-005. На вузьких екранах таблиця виходить за межі сторінки
- **Severity:** Minor  **Priority:** Medium
- **Кроки:** відкрити головну сторінку у вікні шириною 390 px (Chrome DevTools, режим пристрою).
- **Фактичний результат:** стовпці «Рік», «Сторінок», «Статус», «Дії» обрізані, кнопок «Редагувати»/«Видалити» не видно без прокрутки всієї сторінки.
- **Очікуваний результат:** таблиця прокручується всередині свого блоку або перебудовується в картки.
- **Причина:** у шаблоні немає `<meta name="viewport">`, таблиця не обгорнута в контейнер з `overflow-x: auto`.
- **Автотест:** `test_bug005_viewport_meta_present`
